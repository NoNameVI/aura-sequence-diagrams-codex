# Sources for the AURA profile

The [AURA UC sequence profile](AURA_UC_SEQUENCE_PROFILE.md) defines project conventions. Its UML terminology is informed by the [OMG UML 2.5.1 specification](https://www.omg.org/spec/UML/2.5.1/PDF), especially chapter 17 on Interactions. Diagramming examples and tool behavior are informed by the [Visual Paradigm Sequence Diagram Handbook](https://www.visual-paradigm.com/learning/handbooks/software-design-handbook/sequence-diagram.jsp?format=pdf), [sequence diagram tutorial](https://online.visual-paradigm.com/diagrams/tutorials/sequence-diagram-tutorial/), and [user guide](https://www.visual-paradigm.com/support/documents/vpuserguide/94/2577/7025_drawingseque.html).

These sources explain UML notation; the AURA-specific rules on numbering, lifelines, `ref` naming, page layout, and release deliverables are the project owner's conventions.
